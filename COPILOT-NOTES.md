# Copilot Notes

## Prompt Used

I asked Copilot to generate a professional GitHub Profile README using my real educational background, current projects, and actual skills. I instructed it not to invent experience, certifications, or achievements.

## One Thing Copilot Got Right

It generated a clean README structure with sections for introduction, projects, tech stack, and contact information.

## One Thing Copilot Got Wrong

It added technologies and achievements that I have not actually used. I removed those to ensure every claim in the README is accurate.
